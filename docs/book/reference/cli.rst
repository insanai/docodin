.. _cli-reference:

========================
Command-line reference
========================

This chapter lists every command and option of docodin's tools.  The options of the
native ``docodin`` command are docutils' front-end options; each entry names the docutils
setting it sets, which is also the key for ``settings_overrides`` in Python
(:doc:`settings`).

docodin (native)
================

.. code-block:: text

   docodin [--writer=NAME] [options] [SOURCE [DESTINATION]]
   docodin WRITER [options] [SOURCE [DESTINATION]]
   docodin check [options] FILE...
   docodin pdf [--engine=NAME] [options] SOURCE [OUTPUT.pdf]
   docodin book build [DIR] [options]
   docodin dod new|list|index|check [options]
   docodin sphinx [sphinx-build arguments]

The native program, installed by the wheel into the environment's ``bin`` directory.
Converts reStructuredText into HTML5, LaTeX, XeLaTeX, Docutils XML or pseudo-XML exactly
as docutils 0.22 does, without Python.  Reads ``SOURCE`` (default: standard input, also
``-``) and writes ``DESTINATION`` (default: standard output).  ``WRITER`` is one of
``html``, ``html5``, ``xhtml``, ``latex``, ``latex2e``, ``xetex``, ``xml`` and
``pseudoxml``.  When the program is called ``rst2html``, ``rst2html5``, ``rst2latex``,
``rst2xetex``, ``rst2xml`` or ``rst2pseudoxml`` (a link to ``docodin``), the name selects
the writer.  ``WRITER`` may also be an ``rst2*`` name of the Python front end: ``rst2man``,
``rst2odt`` and ``rst2s5`` select writers that ``python -m docodin`` runs.  Configuration
files are not read.

``docodin --help`` lists the general options and those of the html5 writer; ``docodin
--help --writer=NAME`` those of another writer.  Exit status: see
:doc:`../guide/command-line`.

General options
---------------

These options apply to every writer.

``--writer=<writer>``
   Writer: html5 (html, xhtml), latex, xetex, xml or pseudoxml (default: html5).

``--output-path, --output, -o=<destination>``
   The output file (default: DESTINATION or standard output).  Setting: ``output_path``.

``--title=<title>``
   The document title.  Setting: ``title``.

``-g, --generator``
   Include a "Generated by Docutils" credit and link.  Setting: ``generator``.

``--no-generator``
   No generator credit (default).  Setting: ``generator``.

``-d, --date``
   Include the date at the end of the document (UTC).  Setting: ``datestamp``.

``-t, --time``
   Include the time and date (UTC).  Setting: ``datestamp``.

``--no-datestamp``
   No datestamp (default).  Setting: ``datestamp``.

``--root-prefix=<path>``
   Base directory of absolute paths.  Setting: ``root_prefix``.

``-s, --source-link``
   Include a "View document source" link.  Setting: ``source_link``.

``--source-url=<URL>``
   The URL of the source link.  Setting: ``source_url``.

``--no-source-link``
   No source link (default).  Setting: ``source_link``.

``--toc-entry-backlinks``
   Link section headers to their table of contents entry.  Setting: ``toc_backlinks``.

``--toc-top-backlinks``
   Link section headers to the top of the table of contents.  Setting:
   ``toc_backlinks``.

``--no-toc-backlinks``
   No links from section headers to the table of contents.  Setting: ``toc_backlinks``.

``--footnote-backlinks``
   Link from footnotes and citations to their references (default).  Setting:
   ``footnote_backlinks``.

``--no-footnote-backlinks``
   No links from footnotes and citations to their references.  Setting:
   ``footnote_backlinks``.

``--section-numbering``
   Number sections with the "sectnum" directive (default).  Setting: ``sectnum_xform``.

``--no-section-numbering``
   Leave the numbering of the "sectnum" directive to the writer (LaTeX numbers sections
   itself).  Setting: ``sectnum_xform``.

``--strip-comments``
   Remove comment elements.  Setting: ``strip_comments``.

``--leave-comments``
   Keep comment elements (default).  Setting: ``strip_comments``.

``--strip-elements-with-class=<class>``
   Remove elements with this class.  Setting: ``strip_elements_with_classes``.

``--strip-class=<class>``
   Remove this class value from elements.  Setting: ``strip_classes``.

``-r, --report=<level>``
   Report messages at or above this level (default: warning).  Setting:
   ``report_level``.

``-v, --verbose``
   Report all messages (--report=info).  Setting: ``report_level``.

``-q, --quiet``
   Report no messages (--report=none).  Setting: ``report_level``.

``--halt=<level>``
   Stop at a message of this level (default: severe).  Setting: ``halt_level``.

``--strict``
   Stop at any message (--halt=info).  Setting: ``halt_level``.

``--exit-status=<level>``
   Exit with 10 + the highest message level at or above this level.  Setting:
   ``exit_status_level``.

``--debug``
   Report debug messages.  Setting: ``debug``.

``--no-debug``
   No debug messages (default).  Setting: ``debug``.

``--warnings=<file>``
   Write the messages to this file (default: standard error).  Setting:
   ``warning_stream``.

``--traceback``
   Show a Python traceback when an exception stops processing (Python front end).
   Setting: ``traceback``.

``--no-traceback``
   No traceback (default).  Setting: ``traceback``.

``--input-encoding=<name[:handler]>``
   Encoding of the source (utf-8, utf-8-sig, latin-1, ascii).  Setting:
   ``input_encoding``.

``--input-encoding-error-handler=<handler>``
   Error handler for undecodable input: strict (default), ignore or replace.  Setting:
   ``input_encoding_error_handler``.

``--output-encoding=<name[:handler]>``
   Encoding of the output (utf-8, utf-8-sig, utf-16, utf-32, latin-1, ascii).  Setting:
   ``output_encoding``.

``--output-encoding-error-handler=<handler>``
   Strict, xmlcharrefreplace, backslashreplace, replace or ignore.  Setting:
   ``output_encoding_error_handler``.

``-e, --error-encoding=<name[:handler]>``
   Encoding of the messages (default: utf-8).  Setting: ``error_encoding``.

``--error-encoding-error-handler=<handler>``
   Error handler for unencodable messages (default: backslashreplace).  Setting:
   ``error_encoding_error_handler``.

``-l, --language=<tag>``
   The document language (BCP 47 tag, default: en).  Setting: ``language_code``.

``--id-prefix=<prefix>``
   Prefix of all generated ids.  Setting: ``id_prefix``.

``--auto-id-prefix=<prefix>``
   Prefix of automatically numbered ids (default: %).  Setting: ``auto_id_prefix``.

``--expose-internal-attribute=<attribute>``
   Show an internal attribute of the nodes in the XML and pseudo-XML output
   (repeatable).  Setting: ``expose_internals``.

``--strict-visitor``
   Fail on node types that a writer does not know (for development).  Setting:
   ``strict_visitor``.

``--no-file-insertion``
   Disable the "include" directive and file access of "raw" and tables.  Setting:
   ``file_insertion_enabled``.

``--file-insertion-enabled``
   Allow file insertion (default).  Setting: ``file_insertion_enabled``.

``--no-raw``
   Disable the "raw" directive and role.  Setting: ``raw_enabled``.

``--raw-enabled``
   Allow the "raw" directive and role (default).  Setting: ``raw_enabled``.

``--line-length-limit=<length>``
   Maximal line length (default: 10000).  Setting: ``line_length_limit``.

``--validate``
   Validate the document tree.  Setting: ``validate``.

``--no-validation``
   Do not validate the document tree (default).  Setting: ``validate``.

``--pep-references``
   Recognize and link PEP references ("PEP 258").  Setting: ``pep_references``.

``--pep-base-url=<URL>``
   Base URL of PEP references (default: https://peps.python.org/).  Setting:
   ``pep_base_url``.

``--pep-file-url-template=<URL>``
   File name of PEP references (default: pep-%04d).  Setting: ``pep_file_url_template``.

``--rfc-references``
   Recognize and link RFC references ("RFC 822").  Setting: ``rfc_references``.

``--rfc-base-url=<URL>``
   Base URL of RFC references (default: https://tools.ietf.org/html/).  Setting:
   ``rfc_base_url``.

``--tab-width=<width>``
   Tab stop width (default: 8).  Setting: ``tab_width``.

``--trim-footnote-reference-space``
   Remove the space before footnote references.  Setting:
   ``trim_footnote_reference_space``.

``--leave-footnote-reference-space``
   Keep the space before footnote references (default).  Setting:
   ``trim_footnote_reference_space``.

``--syntax-highlight=<format>``
   Code token classes (without Pygments, as "none").  Setting: ``syntax_highlight``.

``--smart-quotes=<yes/no/alt>``
   Typographic quotes, dashes and ellipses (alt: alternative quotes).  Setting:
   ``smart_quotes``.

``--smartquotes-locales=<language:quotes[,...]>``
   Quote characters for languages, as language:quotes pairs.  Setting:
   ``smartquotes_locales``.

``--word-level-inline-markup``
   Recognize inline markup at word boundaries only (default).  Setting:
   ``character_level_inline_markup``.

``--character-level-inline-markup``
   Recognize inline markup within words.  Setting: ``character_level_inline_markup``.

``--no-doc-title``
   Do not promote a lone top-level section title to the document title.  Setting:
   ``doctitle_xform``.

``--no-doc-info``
   Do not turn the first field list into bibliographic data.  Setting:
   ``docinfo_xform``.

``--section-subtitles``
   Promote lone subsection titles to section subtitles.  Setting:
   ``sectsubtitle_xform``.

``--no-section-subtitles``
   Do not promote subsection titles (default).  Setting: ``sectsubtitle_xform``.

``--config=<file>``
   Read a configuration file (the command then runs through Python).  Setting:
   ``config``.

``--record-dependencies=<file>``
   Write the files the output depends on to a file (through Python).  Setting:
   ``record_dependencies``.

``--dump-settings``
   Print the settings after processing (through Python).  Setting: ``dump_settings``.

``--dump-internals``
   Print the document's internal attributes after processing (through Python).  Setting:
   ``dump_internals``.

``--dump-transforms``
   Print the applied transforms after processing (through Python).  Setting:
   ``dump_transforms``.

``--dump-pseudo-xml``
   Print the document tree as pseudo-XML after processing (through Python).  Setting:
   ``dump_pseudo_xml``.

``-V, --version``
   Print the version and exit.

``-h, --help``
   Print this help and exit.

docodin pdf
===========

.. code-block:: text

   docodin pdf [--engine=NAME] [options] SOURCE [OUTPUT.pdf]

Writes ``SOURCE`` with the ``latex`` writer (the ``xetex`` writer for ``xelatex`` and
``lualatex``) to ``OUTPUT.tex`` and compiles it to ``OUTPUT.pdf``, running the engine
twice.  The default output is the name of ``SOURCE`` with ``.pdf``, in the current
directory.  The options are those of the LaTeX writers.

``--engine=NAME``
   ``pdflatex`` (the default when it is installed), ``xelatex`` (the default otherwise)
   or ``lualatex``, or a path to an engine.

docodin check
=============

.. code-block:: text

   docodin check [options] FILE...

Reports the markup errors the parser detects, one file after another.

``--error-format=FORMAT``
   ``elm`` (explained reports, the default) or ``docutils``.
``--color=WHEN``
   Colour Elm reports: ``auto`` (the default), ``always`` or ``never``.
``--report=LEVEL``
   Report messages at or above ``LEVEL`` (default: ``warning``).
``--exit-status=LEVEL``
   Exit with status 1 if a message at or above ``LEVEL`` was reported (default:
   ``error``).
``-h``, ``--help``
   Print the help and exit.

docodin book
============

.. code-block:: text

   docodin book build [DIR] [options]

Builds the Sphinx project in ``DIR`` (default: the current directory) without Python: an
HTML site in the docodin theme (``OUTDIR/html``) and a PDF book (``OUTDIR/latex``).
``conf.py`` is read, not run: its plain assignments count (:doc:`settings`).  Without
``--html`` or ``--pdf``, both are built (the PDF when a TeX engine is found).
:doc:`../development/documentation` describes the project format; DOD 18 the design.

``-o OUTDIR``, ``--output=OUTDIR``
   The output directory (default: ``DIR/_build``).
``--html``
   Build the HTML site.
``--pdf``
   Build the PDF book.
``--engine=NAME``
   ``lualatex`` (default: ``conf.py``'s ``latex_engine``) or ``xelatex``.
``--error-format=FORMAT``
   ``elm`` (explained reports, the default) or ``docutils``.
``--color=WHEN``
   Colour Elm reports: ``auto`` (the default), ``always`` or ``never``.
``--exit-status=LEVEL``
   Exit with 10 plus the highest level of the warnings if it is ``LEVEL`` or above
   (default: ``none``), as docutils does.
``-W``
   The same as ``--exit-status=warning``.
``-q``, ``--quiet``
   Print warnings only.
``-h``, ``--help``
   Print the help and exit.

Sources are read as UTF-8 (with or without a byte-order mark).  A source that cannot be
read (UNREADABLE SOURCE) or decoded (SOURCE IS NOT UTF-8) is a SEVERE problem: the build
reports every such source, writes nothing and exits with status 1.  A project that is not
a Sphinx project, or a usage error, exits with status 2.

docodin dod
===========

.. code-block:: text

   docodin dod new "Title" [--number=N] [--labels=a,b] [--author=A] [--dir=DIR]
   docodin dod list [--state=STATE] [--label=LABEL] [--dir=DIR]
   docodin dod index [--dir=DIR]
   docodin dod check [--dir=DIR] [--error-format=FORMAT] [--color=WHEN]

Manages the DocOdin Discussions in ``DIR`` (default: ``docs/dod``;
:doc:`../development/dod-process`).

``new``
   Creates ``NNNN-slug.rst`` from ``0000-template.rst``: the next free number (after the
   records' numbers and those of the ``dod/NNNN`` git branches) or ``--number``, the
   labels of ``--labels``, the author (``--author="Name <email>"``, or else
   ``user.name`` and ``user.email`` from git's configuration), today's date and the state
   ``prediscussion``.  Without either author, the command stops and says how to name one.
``list``
   Prints a table of the records, optionally only those with a state (``--state``) or a
   label (``--label``).
``index``
   Rewrites the records by state in ``index.rst``, between the comments
   ``.. dod-index-start`` and ``.. dod-index-end``.
``check``
   Checks the file names, titles, fields, states, labels, dates, numbers and the index.
``--dir=DIR``
   The directory of the records.

``new`` exits with status 2 (NO AUTHOR) when it finds no author.

docodin sphinx
==============

.. code-block:: text

   docodin sphinx [sphinx-build arguments]

Runs ``python -m docodin sphinx`` with the arguments, the standard streams and the exit
status of ``sphinx-build`` (see `python -m docodin`_).  The Python is the first that can
import docodin among ``$DOCODIN_PYTHON``, the ``python3`` or ``python`` in the directory
of the ``docodin`` program, and ``python3`` on the ``PATH``.  Without one, the command
stops with NO PYTHON (status 2).  Sphinx must be installed in that Python's environment
(``pip install docodin[sphinx]``).

docodin-check
=============

.. code-block:: text

   docodin-check [options] [FILE ...]

Checks reStructuredText files for markup errors at native speed.  Reads standard input
when no ``FILE`` (or ``-``) is given.  Reports are written to standard error.  Only
parser diagnostics are reported: directives, roles and reference resolution are left to
the publisher.

``--report=LEVEL``
   Report messages at or above ``LEVEL`` (default: ``warning``).
``--exit-status=LEVEL``
   Exit with status 1 if a message at or above ``LEVEL`` was reported (default:
   ``error``).
``--error-format=FORMAT``
   ``elm``: explained reports with source excerpts and hints (the default);
   ``docutils``: ``source:line: (LEVEL/n) message`` lines.
``--color=WHEN``
   Colour Elm reports: ``auto`` (the default), ``always`` or ``never``.
``--tab-width=N``
   Tab stop width (default: 8).
``--line-length-limit=N``
   Maximal line length (default: 10000).
``--pep-references``
   Recognise PEP references.
``--rfc-references``
   Recognise RFC references.
``--character-level-inline-markup``
   Recognise inline markup within words.
``--trim-footnote-reference-space``
   Remove the space before footnote references.
``-j N``, ``--jobs=N``
   Number of worker threads (default: the number of CPUs).
``--version``
   Print the version and exit.
``-h``, ``--help``
   Print the help and exit.

``LEVEL`` is one of ``info``, ``warning``, ``error``, ``severe``, ``none``, or 1 to 5.
The exit status is 0, 1 when a message reached the ``--exit-status`` level or a file could
not be read, and 2 for a usage error.

===========

.. code-block:: text

   Communicate over standard input and output (the default).
``--version``
   Print the version and exit.
``-h``, ``--help``
   Print the help and exit.

docodin-sphinx-build
====================

.. code-block:: text

   docodin-sphinx-build [sphinx-build arguments]

``sphinx-build`` with docutils served by docodin.  Takes exactly the arguments of
``sphinx-build``.  With ``DOCODIN_GC=tuned`` in the environment, the garbage collector is
tuned for the build (:doc:`../guide/sphinx`).

python -m docodin
=================

.. code-block:: text

   python -m docodin [--writer=NAME] [docutils options] [SOURCE [DESTINATION]]
   python -m docodin WRITER [docutils options] [SOURCE [DESTINATION]]
   python -m docodin sphinx [sphinx-build arguments]

The Python front end.  Until 0.2.0 the wheel also installed it as a ``docodin``
command; since 1.0.0b1 that name belongs to the native program, which runs this front
end for what needs Python.

docutils' ``publish_cmdline`` with ``docodin.Parser``: every docutils option, writer and
configuration file.  The default writer is ``html5``.  ``WRITER`` is a writer name or an
alias: ``html`` (html5), ``rst2html``, ``rst2html5``, ``rst2latex``, ``rst2xetex``,
``rst2xml``, ``rst2pseudoxml``, ``rst2man`` (manpage), ``rst2odt`` (odt) and ``rst2s5``
(s5).  ``python -m docodin sphinx`` patches docutils' parser with docodin's and runs
``sphinx-build`` with the remaining arguments.
